# 常见问题

[返回首页](../README.md) · [图文入门](入门教程.md) · [反馈问题](GitHub下载与反馈.md#遇到问题怎么反馈)

本页的界面名称对应 NestPack 1.1.0。

## 下载后只有代码文件，找不到程序

你下载的是源码包。打开[发布页](https://github.com/codeTianZun/NestPack/releases)，在 **Assets** 中选择适合自己系统的文件。Windows 图形界面使用 `NestPack.exe`。

具体位置见[GitHub 下载指南](GitHub下载与反馈.md#下载哪个文件)。

## 为什么我的界面和截图不一样

本教程截图对应 1.1.0，顶部有「压缩」「解包」页签。1.0.0 使用旧界面，请在发布页核对下载版本。

需要从源码运行或构建时，参照[打包说明](../打包说明.md)。反馈时请注明版本、程序来源和下载日期。

## 提示找不到 WinRAR 或 7-Zip

点击「设置 → 重新检测」，按本次任务所用格式检查：

| 压缩层格式 | 所需工具 | 操作 |
|---|---|---|
| 7z、ZIP | 7-Zip | 点击「安装/修复 7-Zip」，完成后重新检测 |
| RAR | WinRAR | 点击「WinRAR 安装指引」，从官网安装后重新检测 |

已安装但未检测到时，可通过相应行的「浏览」选择工具程序。ZIP 需要 `7z.exe`、`7za.exe` 或 `7zz.exe`；检测为“仅支持 7z”的 `7zr.exe` 无法创建 ZIP。

本次任务只有 7z 和 ZIP 层时，只需准备 7-Zip。若仍提示缺少 WinRAR，检查列表中是否还留有 RAR 层。

## 为什么完成后只有最外层文件

默认开启「自检通过后删除上一层」。内层被装入外层且自检成功后，程序会删除输出目录里单独的内层文件，保留最终交付文件。

原始来源保留，内层也仍在外层压缩包中。希望输出目录保留每一层时，在运行前展开「任务选项」，关闭「自检通过后删除上一层」。

## 密码正确，但还是解不开

先按以下顺序检查：

1. 候选密码每行只填一个密码，保留密码本身的大小写、符号和空格。完成窗口复制出的整份清单包含层名和路径，需要从中取出密码再填写。
2. 每层可以使用不同的密码。把所有加密层的密码分别填写在各行，顺序不限。
3. 分卷归档应收齐全部分卷，放在同一目录，并选择第一卷。
4. 查看完整报错。如果提示数据损坏或文件不完整，核对下载是否完成，并向发送者确认文件和密码。

当前配置里已填写的密码会自动用于解包。若关闭了配置密码保存，重启后需要重新填写；密码遗失后，NestPack 无法恢复。

## 只收到一个分卷，能先解开吗

请先收齐同一套的全部分卷，再开始解包。完整文件的内容可能分布在多卷中。

把所有分卷放在同一个目录，选择首卷，例如 `资料_2.zip.001`、`资料_1.7z.001` 或 `资料_1.part1.rar`。后续卷会由工具自动读取。

## 提示输出文件已存在

压缩时，可以更换输出目录或修改压缩包名称。如果确认要替换旧结果，在「任务输出 → 输出选项」启用「覆盖同名输出」。

解包时，请选择一个空目录或先移走其中的同名内容。解包遇到同名文件会停止，以免覆盖已有文件。

## 分别打包时，为什么只改了一个文件夹的设置

在「分别打包」模式中，选中来源后修改层设置，会为这个来源建立独立设置。

要统一修改仍共用默认的来源，点击「编辑默认层设置」。已经独立设置的来源，需要选中后点击「恢复共用默认」，才会重新跟随默认层。操作示例见[多个文件夹分别打包](进阶用法.md#多个文件夹分别打包)。

## 关掉软件后，设置和密码还在吗

界面修改会自动保存，保存状态显示在顶部配置栏。默认配置和 GUI 状态文件位于程序同目录，建议将程序放在自己可写的文件夹中。

「配置操作 → 在配置中保存密码」开启时，密码会以明文保存。关闭后，密码只保留在当前会话中；退出前保存好密码清单。

## MP4 在本地能播放，为什么网盘不能预览

网盘使用自己的解析与转码方式，不同平台的支持情况可能不同。先确认原文件可以本地播放，并能在 NestPack 中正常解包。

需要恢复归档时，下载上传的原始文件。转码或另存得到的视频可能不再包含归档。兼容性说明见[视频融合](../使用说明.md#视频融合)。

## 双击程序没有反应，或出现其他错误

记录系统提示；如果程序能打开，点击「查看日志」。打不开时，按[日志查找步骤](GitHub下载与反馈.md#去哪里找日志)查看 `nestpack.log`。

仍无法解决时，按[反馈指南](GitHub下载与反馈.md#遇到问题怎么反馈)提交问题，附上程序来源、系统、操作步骤和报错。公开截图及日志前检查其中的密码和私人路径。
