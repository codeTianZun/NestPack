# Qt 6.11.2 许可与署名材料

NestPack 1.0.0 的 Windows GUI 使用 PySide6 6.11.2，打包 Qt Core、GUI、Widgets、SVG、SVG Widgets、XML 和 Windows 平台插件。本目录保存相应 Qt 模块的开源许可文本，以及 Qt Core、GUI、SVG 第三方组件的版权声明与其引用的许可文本。

文件保持 Qt 官方源码中的相对路径，来源为以下 `v6.11.2` 标签：

- [qtbase](https://github.com/qt/qtbase/tree/v6.11.2)
- [qtsvg](https://github.com/qt/qtsvg/tree/v6.11.2)

`qt_attribution.json` 记录组件名称、使用位置、版权与许可。`LICENSES/` 和相应组件目录下的许可文件提供许可原文。Windows 构建还会收集已安装 Python 包附带的许可文件，一同放入发布包的 `licenses/` 目录。
